How it works

The plan for the local app.

Dum is intended to start from your terminal. A command opens a local page with its screen already sharing, ready for you to follow along.

1. Pair with Dum

The screen is the main view, with a text box beside it for questions and requests. The little intern sits below the screen with short progress updates.

2. Keep a skill tree

A separate tab holds the things you want to learn. Suggest a topic and add it to your tree, then return to it alongside your project.

3. Run it locally

The pairing session is meant to run on localhost. The public website is an introduction, not the screen-sharing application.

The terminal launcher and live screen-sharing flow aren't implemented in this repository yet. There isn't an install command for them.

See the source and project README for the code and development setup.
