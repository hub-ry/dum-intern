How it works · Source

Dum is a pair-programming project built around a shared screen and a conversation about the code.

1. The pairing session

Dum's screen is the main view. A simple text box beside it gives you a place to ask questions and talk through the next step.

2. A skill tree

Suggest something you'd like to learn. Add it to your tree and come back to it as you work.

3. From your terminal

The intended flow is one command that opens a localhost page with Dum already sharing its screen. The pairing app runs on your machine; this website is its introduction.

The local launcher and screen-sharing flow aren't available yet. The source is on GitHub.
