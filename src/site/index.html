A skill tree for what you want to build.

Open your Dum · How it works · Source

Pick a goal. Break it into things to learn. Each block has a reading; finishing it unlocks the block. A build is a stack of the blocks you've unlocked.

1. The loop

  • Set a goal. Say what you want to be able to build. Dum drafts the blocks, or you write them yourself.
  • Read. Open a block's paper. Reaching the last page unlocks it.
  • Already know it? Swear it in a sentence. The block unlocks and stays marked as sworn.
  • Stack. Choose unlocked blocks and put them in order. Save that stack as a build.

2. The readings

  • LaTeX articles in the same format as learn.ryhub.dev.
  • You write and compile them in Cursor with the repo's dum-paper skill, then put the PDFs in your Dum folder. The server doesn't generate them.
  • No quiz or submission. Reading to the end unlocks the block; it isn't a claim of mastery.

3. Your Dum is a folder

The goal, tree, readings, and saved builds live together. The default root is dum; you can choose another folder.

dum/

  • Sign in with GitHub to open your workspace.
  • Start from the folder template. Fork the repo if you want it in git.
  • The site stores your workspace on hub. Nothing in it is published unless you put it in a public repo yourself.
