A personal intern for your Git repo

Dum is a small intern on your Mac that you train as you build.

It sits next to your editor and can only write code for skills you've taught it. You teach it by explaining a skill in your own words or by handing in code you wrote without AI, so each thing it learns is something you've learned too.

01 / THE QUESTION

“I’m doing almost everything with AI during my internship. What do I do?”

Asked on r/cscareerquestions ↗

Someone asked this on r/cscareerquestions. With Dum, you have an intern of your own, and its skill tree starts empty. Before it can take on more of the work, you have to teach it, so you end up understanding each skill it uses.

Some skills unlock when you explain them in your own words. Others need code you wrote without AI first. You still build in your own editor, and the wizard next to Dum gives advice now and then.

03 / THE LEARNING LOOP

How the explaining part works

  1. 01

    Pick a real decision in the work.

  2. 02

    Explain your approach in everyday words.

  3. 03

    Notice what is still fuzzy. Revisit it, then build.

This borrows from the Feynman technique. Explaining something can count as recognizing a skill on your tree. It doesn't count as proof you built it.
