install Dum

Dum is a small intern on your Mac that you train as you build.

It sits next to your editor and only writes code for skills you've taught it. You teach it by explaining a skill in your own words, or by handing in code you wrote without AI. It ends up knowing what you know.

“I’m doing almost everything with AI during my internship. What do I do?”

r/cscareerquestions ↗

Dum is one answer: keep using AI, but only for the parts you already understand. Its skill tree starts empty and grows when you do.

You still build in your own editor. The wizard next to Dum drops in with advice now and then.

How the explaining part works

  1. Pick a real decision in the work.
  2. Explain your approach in everyday words.
  3. Notice what's still fuzzy. Go back to it, then build.

It's the Feynman technique. An explanation marks a skill as recognized on your tree. Marking it as built takes code you wrote yourself.
