Set a goal. Dum lays out the blocks. Read the assignment to unlock one, or swear you already know it. When you build, stack the blocks you unlocked, in the order you want.

Sign in with GitHub How it works

Your Dum is a folder. The default name is dum. You can point it at another root.

One loop, start to finish

  1. Set a goal Say what you want to be able to build. Dum drafts a skill tree, or you write the blocks yourself.
  2. Read Each block has a paper in the same format as learn.ryhub.dev. You write it in Cursor. The last page unlocks it. Hub does not write or compile it.
  3. Swear If you already know a block, say so. It unlocks without the reading, and the tree marks it sworn.
  4. Stack A build is unlocked blocks in an order you choose. Hints list what to read next and what you can stack now.

The workspace is a folder in your account on hub. Fork the base repo if you want the folder in git. Read the details.
