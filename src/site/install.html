Installation

Mac app

Prerequisites

  • macOS 13 or later
  • Git — comes with Apple's Command Line Tools; dum offers to install them if missing
  • A Claude subscription that includes claude-opus-5-5 and claude-fable-5-1. No API key or paid-usage route. The subscription must grant access to both models.

The app carries its own Node and Claude Code runtime. No terminal is needed.

Optional bundled voice dictation needs macOS 14 or later on Apple Silicon. It uses OpenSuperWhisper's local model and your configured recording shortcut; microphone and Accessibility permissions are required.

First run

  1. Open the DMG, drag Dum into Applications, and launch it.
  2. If macOS blocks it: open System Settings → Privacy & Security → Security → Open Anyway.
  3. Sign in to Claude when prompted. Dum never sees your password.
  4. Choose a Git project folder.
  5. Click the characters or press Cmd+Shift+D to open the conversation.

Dum lives in the menu bar and a small floating pair. There is no Dock icon.

Source install

Prerequisites

  • Node 22.6 or later
  • Git
  • The claude CLI, logged into a Claude subscription with claude-opus-5-5 and claude-fable-5-1

Terminal edition

claude auth login
npm install
npm link
cd your-project
dum

Desktop app from source

npm run desktop        # compile and launch
npm run desktop:pack   # unpacked app for this OS
npm run desktop:mac    # DMG and ZIP (run on a Mac)

Linux and Windows: the terminal edition works on any platform Node supports. The packaged desktop app is macOS only.

Newer test builds are artifacts of the desktop macOS workflow. Signed-in GitHub accounts can download them directly.

Let a terminal LLM set it up

Prefer to paste one instruction into the terminal agent you already use? This walks it through the source install, checks each step, and stops when it needs you.

paste into your terminal LLM 
Set up Dum from https://github.com/hub-ry/dum-intern for me.

Work one step at a time. Check the result before continuing. Ask me before:
- using sudo or installing anything system-wide
- opening a browser for Claude login or completing 2FA
- entering, copying, storing, or relaying passwords, one-time codes, recovery codes, or security keys
- writing outside the folder I give you
- changing an existing project or deleting anything

1. Check my OS, Node version, Git version, and whether the `claude` CLI is installed.
2. If this is a Mac, use the source install. If it is Linux or Windows, explain that the terminal edition is the supported path.
3. Ask where I want the repository. Clone it there if it is not already present.
4. In the repository, run `npm install` and then `npm link`.
5. Check Claude authentication. If I am not logged in, ask before running `claude auth login`. If Claude asks for browser login, 2FA, a passkey, an OTP, or a recovery code, stop and tell me to complete it myself. Never request, enter, store, or relay those secrets. Wait for me to confirm, then check authentication again.
6. Ask which Git project I want to use, then run `dum` from that project.
7. If a step fails, stop and show the exact next command. At the end, print the remaining setup steps and wait for me.

The prompt asks the agent to stop before auth, 2FA, system changes, or project edits. Never give an agent your password, one-time code, recovery code, or security key. Review its commands like any other shell command.
