# Your Dum

This folder is the workspace. dumintern.com reads and writes it after you sign in. You can keep the folder named `dum`, or point Dum at another root.

- `goal.md` is the goals, in words.
- `tree.json` is the skill tree, what is unlocked, and the builds.
- `readings/` holds one brief per block, then a learn-format paper once you write it. Cursor's dum-paper skill writes and compiles the paper on your machine. A block unlocks when you reach the last page of that PDF, or when you swear you already know it. Hub does not write or compile papers.
- `builds/` is each stack of unlocked blocks, in the order you chose.

The base of this folder lives in the dum-intern repo. Fork the repo and this folder is yours.
